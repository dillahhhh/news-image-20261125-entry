One image summing up Wednesday 25 November 2026's world news: Ukraine's confirmed strikes on two Russian ships lead the page, with Tuesday's market close, six more stories from Hormuz to Paris, a world map with twelve numbered pins, and a date-check box separating today's news from older headlines.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the pre-rendered `entry.png` (drawn by `render.py` from `stories.json`) to the output directory. Standard library only, no network, deterministic output.
